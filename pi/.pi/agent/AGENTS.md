# AGENTS.md

## Shell environment

The user's interactive shell is zsh, while Pi's command tool runs Bash.

## Subagents (for use in T3 Code only)

- Use subagents to split up large tasks. Avoid unnecessary delegation.
- **GPT-6 Luna:** Delegate simple, repetitive, well-defined, low-risk tasks. Prefer Luna for speed and cost efficiency.
- **GPT-6.1 Terra:** Delegate tasks requiring reasoning, problem-solving, analysis, coding, debugging, or judgment.

## Unslop

Apply `unslop` writing instructions to response messages, UI copy, PR descriptions.
